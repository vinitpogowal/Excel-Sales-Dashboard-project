📊 Excel Sales Dashboard

An interactive Excel dashboard for analyzing sales performance, revenue, and regional trends.

📸 Dashboard Preview

"Sales Dashboard" (./Screenshot%202026-10-24%20225922.png)

🎯 Project Objective

The objective of this project is to transform raw sales data into an interactive and visually appealing dashboard that provides useful business insights.

📈 Dashboard Features

- Total Revenue analysis
- Regional-wise revenue analysis
- Country-wise revenue analysis
- Top 5 countries by revenue
- Interactive slicers and filters
- PivotTables and PivotCharts
- Data visualization for quick business insights

🛠️ Tools & Skills

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel Formulas
- Data Analysis
- Data Visualization
- Dashboard Design

🔍 Key Insights

This dashboard can be used to identify:

- Overall revenue performance
- Top-performing countries
- Regional sales performance
- Differences in revenue across countries and regions
